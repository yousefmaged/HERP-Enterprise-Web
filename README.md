# HERP — نظام إدارة الأعمال

**HERP** هو إصدار أولي مفتوح المصدر لنظام إدارة موارد المؤسسة بواجهة عربية كاملة واتجاه RTL. يقدّم مساحة عمل مؤسسية موحّدة للعمليات اليومية، مع واجهة داكنة، وصلاحيات مبنية على الأدوار، وطبقة بيانات تحمي عزل كل مؤسسة عن غيرها.

> الهدف من HERP هو جعل مؤشرات العمل والعمليات الأساسية قابلة للإدارة من شاشة واحدة، مع بقاء كل وحدة مستقلة وقابلة للتوسع.

## ما الذي يتضمنه الإصدار الحالي؟

| المجال | ما هو متاح الآن |
|---|---|
| لوحة القيادة | مؤشرات إيرادات وموظفين ومخزون وعملاء، ومخطط مبيعات، وتنبيهات ومهام. |
| الصلاحيات | عضويات متعددة المؤسسات بأدوار: مدير عام، مدير وحدة، موظف، مع نطاق وحدات مسموح. |
| الموارد البشرية | الموظفون، الإجازات، الحضور، ومسيرات الرواتب كمسودات. |
| المالية | دليل الحسابات، الفواتير، القيود اليومية المتوازنة، وميزان المراجعة. |
| المخزون | الأصناف، حركات الوارد والصادر والتسويات، وتنبيهات حد إعادة الطلب. |
| CRM | العملاء، الفرص، المتابعات، والتنبيهات المرتبطة بالمتابعة. |
| التقارير | ملخصات تشغيلية وتصدير CSV حسب الوحدة وجدولة تقارير محفوظة بانتظار التفعيل. |
| المساعد الذكي | إجابات عربية مقيدة ببيانات لوحة القيادة المتاحة للمستخدم. |

## البنية التقنية

يعتمد هذا الإصدار على React وTypeScript في الواجهة، وExpress وtRPC في الخادم، وDrizzle ORM مع MySQL/TiDB للبيانات. تطبق الإجراءات المحمية تحققًا من العضوية ونطاق الوحدة قبل قراءة أي بيانات أو تعديلها.

```text
واجهة React RTL
    │ tRPC
خادم Express
    │ إجراءات محمية وصلاحيات مؤسسة
Drizzle ORM
    │
MySQL / TiDB
```

## التشغيل المحلي

بعد استنساخ المستودع، ثبّت الحزم ثم جهّز متغيرات البيئة وقاعدة بيانات متوافقة مع MySQL.

```bash
pnpm install
pnpm drizzle-kit generate
pnpm drizzle-kit migrate
pnpm dev
```

تحتاج بيئة التطوير إلى القيم المعتادة للتطبيق وقاعدة البيانات، وأهمها `DATABASE_URL` و`JWT_SECRET` وبيانات OAuth الموصوفة في قالب المشروع. لا ترفع أي ملف `.env` أو مفاتيح API أو بيانات عملاء إلى المستودع العام.

## الجودة والاختبارات

شغّل الفحوص قبل أي طلب دمج:

```bash
pnpm check
pnpm test
```

تغطي الاختبارات الحالية التحقق من تسجيل الخروج، ومنطق صلاحيات HERP، والتحويلات الرقمية المستخدمة في المؤشرات. يجب أن يضيف كل تغيير في منطق الأعمال اختبارًا مناسبًا.

## خارطة طريق النسخة المكتبية Local-First

الإصدار الحالي هو تطبيق ويب كامل لتسريع التحقق من الوحدات والبيانات والتعاون المفتوح. أما مسار سطح المكتب المحلي المستقل، بما في ذلك Go/Wails وSQLite ومزامنة اختيارية، فموثق في [وثيقة المعمارية المحلية](docs/LOCAL_FIRST_DESKTOP.md). لا يدّعي هذا الإصدار أن البيانات تعمل محليًا دون خادم بعد؛ توضح الوثيقة الحدود والخطوات اللازمة لهذا الانتقال.

## الحالة التشغيلية للجدولة

واجهة إنشاء التقرير اليومي أو الأسبوعي تحفظ الإعداد فقط ولا ترسل بريدًا أو إشعارًا خارجيًا تلقائيًا. يجب تفعيل نقطة تنفيذ مجدولة بعد نشر التطبيق ومراجعة قناة الإرسال وخصوصية بيانات المؤسسة. هذا الفصل مقصود حتى لا يبدأ أي إرسال دوري دون موافقة تشغيلية صريحة.
