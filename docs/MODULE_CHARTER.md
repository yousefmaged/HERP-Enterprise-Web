# ميثاق وحدات HERP

يعرّف هذا الميثاق حدود المسؤولية بين وحدات HERP حتى يمكن للمساهمين تطوير النظام دون إنشاء اعتماد دائري أو تكرار مصدر البيانات.

| الوحدة | مسؤوليتها | البيانات المالكة | نقاط التكامل |
|---|---|---|---|
| النواة والهوية | المؤسسة والعضويات والصلاحيات وسجل التدقيق | `organizations` و`organizationMembers` و`auditLogs` | تتحقق كل عملية من المؤسسة والوحدة قبل قراءة البيانات أو تعديلها. |
| الموارد البشرية | الموظفون والحضور والإجازات والمسيرات | `employees` و`attendanceRecords` و`leaveRequests` و`payrollRuns` | تنشئ مسيرات جاهزة للترحيل المحاسبي؛ ولا تعدّل قيود المالية مباشرة. |
| المالية | دليل الحسابات والفواتير والقيود والتقارير المالية | `chartAccounts` و`invoices` و`journalEntries` و`journalLines` | تستقبل مرجع المصدر من الوحدات الأخرى وتحافظ على القيد المتوازن. |
| المخزون | الأصناف والمستودعات والحركات وإعادة الطلب | `products` و`warehouses` و`stockMovements` | يستهلك التنبيه مستوى إعادة الطلب؛ وتبقى حركة المخزون مصدر الكمية التشغيلي. |
| علاقات العملاء | العملاء والفرص والمتابعات | `clients` و`salesOpportunities` و`crmFollowUps` | ترتبط فواتير المبيعات بالعميل، ولا تنقل CRM الفاتورة إلى حالة مالية بنفسها. |
| العمليات | المهام والتنبيهات والتقارير | `workTasks` و`notifications` و`reportSchedules` | تقرأ مؤشرات الوحدات دون امتلاك بياناتها المصدرية. |
| المساعد الذكي | إجابة الاستفسارات المصرح بها وتحليلها النصي | لا يملك جداول تشغيلية مستقلة | يستدعي إجراءات القراءة المقيّدة نفسها ولا ينفّذ تعديلات مباشرة. |

> كل سجل تشغيلي مرتبط بـ `organizationId`. لا يجوز لأي إجراء جديد تجاوز التحقق من مساحة العمل أو استعمال معرّف مؤسسة يأتي من العميل دون تحقق خادمي.
