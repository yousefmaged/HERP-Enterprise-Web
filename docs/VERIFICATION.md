# التحقق الحالي

تم تشغيل فحص TypeScript واختبارات Vitest بنجاح بعد إضافة الموارد البشرية والمالية. تحققت المعاينة العامة أيضًا من صفحة الدخول العربية في HERP.

تستخدم المعاينة جلسة مستقلة؛ لذلك تظهر حالة تجهيز مساحة العمل عند وجود جلسة معاينة منتهية، ثم تعود صفحة الدخول عند غياب جلسة صالحة. يلزم تسجيل دخول فعلي وتهيئة مؤسسة واحدة للتحقق البصري من بيانات لوحة القيادة ووحداتها داخل مساحة العمل.
